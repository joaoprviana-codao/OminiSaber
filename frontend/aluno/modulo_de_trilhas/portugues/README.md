# Língua Portuguesa

Página dedicada à leitura focada. O layout editorial privilegia um trecho, uma citação e uma paleta de palavras para análise contextual.

A interação principal é a exploração de vocabulário: cada palavra revela uma camada de sentido. O script carrega trilhas e progresso pelo gateway `window.OminiSaber`, filtrando o campo `atividades.trilhas.materia` para calcular o percentual específico de Português.
