# Guia do administrador

## Objetivo

Orientar o gestor na administração acadêmica.

## Funcionamento

O gestor acompanha o mapa institucional, cria contas, administra turmas, professores, alunos, vínculos, descritores, conteúdos publicados, acessos e auditoria.

## Permissões

Ações administrativas exigem sessão autenticada com `role = gestor`.

## Pontos de atenção

Execute migrations no projeto correto e valide policies antes de liberar novas operações.
